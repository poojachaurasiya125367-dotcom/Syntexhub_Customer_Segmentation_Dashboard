# Customer Segmentation Dashboard

## Overview
This project presents an interactive Customer Segmentation Dashboard created using Power BI during my Data Analytics Internship. The dashboard analyzes customer data through Recency, Frequency, and Monetary (RFM) metrics to identify customer segments and provide actionable business insights.

## Tools Used
- Power BI
- Microsoft Excel

## Dashboard Features
- KPI Cards
- Customer Segmentation Analysis
- RFM Metrics
- Interactive Slicers
- Sales & Customer Insights
- Business-Oriented Visualizations
